# 荷兰车险：投保后到正式保单之间的动作清单

适用场景：车主收到保险相关邮件（投保确认、受理部问询、保单附件），需要判断"我现在要做什么"。

## 荷兰车险的典型链条

```
保险经纪 / 比价平台  ──确认投保──▶ 车主
        │
        └──转交──▶ 承保方受理部（acceptatie）──问询/核保──▶ 车主
                          │
                          └──通过后──▶ 出正式 polis + 保险凭证（可能是纸卡/PDF）
```

同一件事的信会来自不同域名的发件人（经纪一个、承保方一个），**不要因为发件域名陌生就当垃圾邮件**，也不要以为"已经确认投保了就不用管"。

## 按邮件类型分派动作

| 邮件 | 必须做的事 |
|---|---|
| 投保确认（含临时承保） | 记下 **voorlopige dekking 到期日**（常见 30 天，自生效日起算）；核对生效日期是否覆盖你实际开始用车的那天 |
| 受理部问车辆用途 | **当天书面回复**。问的是 `bezorgactiviteiten`（配送）是否为除外责任；不实陈述会在理赔时被用来拒赔 |
| "稍后您会收到正式保单" | 设一个提醒：一周内没收到就发信催 |
| 正式 polis / 保险凭证 | 逐项核对（见下表），有出入立刻书面提出并要求更正后的版本 |
| 保费扣款通知 | 核对金额与保单一致，注意手续费是一次性还是每月 |

## 保单核对表

- **车辆识别**：车牌（带不带连字符都算同一辆）、VIN/`meldcode`、品牌型号是否与 RDW 登记一致
- **价值口径**：`cataloguswaarde` 是否含 BTW——与 RDW 的 `catalogusprijs` 比较时要对齐口径，别因为差一个 BTW 就以为保额错了
- **承保范围**：allrisk（全险）/ WA+；casco 部分的自付额 `eigen risico`
- **附加险**：rechtsbijstand、passagiersongevallen、pechhulp（**看等级与地域**，名字带 EXTRA 不等于含国外）
- **里程档**：年里程区间要与实际用量匹配，低报会在理赔时出问题
- **无事故年数** `schadevrije jaren`：直接决定折扣，错一年差不少钱
- **费用结构**：月费 + **保单手续费（投保/终止各收一次）** + 附加险月费，加起来才是真实成本
- **地域**：NL + 欧洲；常跑德国/比利时则确认绿色卡与救援覆盖

## 用户身份带来的差异（企业名下车辆）

- 车辆登记人 / 保单持有人是公司时，**"谁在实际驾驶"和"车辆用于什么业务"是核保的核心问题**，不是形式问题。
- 餐饮/零售类公司名下的车，承保方默认要问配送用途——这几乎是必问题，早点想清楚答案：有就如实说并加保，没有就书面明确否认。
- 公司车的保费支出与 BTW 处理属于记账范畴，不在这里给结论；需要时查 `dutch-business-procedures` / 问会计。

## 别做的事

- 不要在用途问题上替用户"选一个听起来更省钱"的答案——这是理赔时最容易被击穿的地方。
- 不要把"已确认投保"当成"已有保障"：临时承保到期日之前没拿到正式保单，就要主动推进。
- 不要只凭邮件里的"稍后寄送"就认为凭证在路上；一周无音讯即催。
