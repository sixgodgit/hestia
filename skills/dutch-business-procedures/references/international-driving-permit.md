# 荷兰国际驾照 (International Driving Permit / IRB)

> 2026-07-27 研究：30% ruling 换来的荷兰驾照能否办国际驾照

## 核心结论

**可以办，没问题。** 通过 30% ruling 从国内驾照换来的荷兰驾照是 RDW 正式签发的合法驾照，与荷兰人自己考的完全一致。ANWB 发 IDP 只看两样：有效荷兰驾照 + 荷兰居民身份。

## ANWB 办理要求

| 要求 | 详情 |
|------|------|
| 资格 | 荷兰居民（ingezetene）+ 有效荷兰驾照 |
| 办理地点 | ANWB 门店（不能网上办） |
| 所需材料 | 荷兰驾照原件 + 护照照片 |
| 费用 | €24.95（1968年维也纳公约版，3年有效）/ €18.95（1949年日内瓦版，1年有效） |
| 当场取 | 是 |

## 30% ruling 换驾照的特殊注意

- 换驾照时需要有效的 30% ruling（Belastingdienst 的 beschikking）
- **驾照一旦发下来就独立有效**（一般10年），不受 30% ruling 到期影响
- 荷兰驾照上可能有 exchange 代码（70/71/72/73），但 ANWB 不关心来源
- 某些租车公司可能多看一眼，但实践中极少有问题

## 中国驾照 → 荷兰驾照 → IDP 路径总结

```
国内驾照 ──(30% ruling)──→ 荷兰驾照 ──(ANWB)──→ IDP
                                    │
                                    ├── 欧盟直接开 ✅
                                    ├── 美/日/澳/泰 开+IDP ✅
                                    └── 中国回不来 ❌（必须考中国驾照）
```

## 实用建议

- 亚洲热门目的地（日本/韩国/台湾）有 IDP 就不用担心
- 回中国开车：必须重新考科目一（或免考换证，看当地政策），荷兰驾照+IDP 在中国交警面前就是废纸
- 如果主要需求是欧洲+偶尔亚洲出行，办一个 €24.95 的 1968 版 IDP 足够覆盖 3 年
