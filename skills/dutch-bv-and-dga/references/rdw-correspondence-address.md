# RDW 通讯地址（Correspondentieadres）完整指南

配套 `skills/dutch-bv-and-dga/` 的 SKILL.md 使用（Part 2「B.V. 名下车辆管理与 RDW
通讯地址」）。本文保留完整流程与备选方案细节。

## 问题场景
荷兰 B.V.（besloten vennootschap）名下的车辆，所有 RDW 信件（车税单、APK 通知、
罚款、召回信）默认寄到 B.V. 注册地址。如果 B.V. 地址是共享办公/虚拟办公室，信件
可能无人签收，导致滞纳金叠加。

## 解决方案一：RDW Correspondentieadres（最正规）

### 官方说明
来源：https://www.rdw.nl/uw-voertuig-en-uw-gegevens/uw-gegevens-bekijken-of-veranderen/naam-of-adres-in-het-register-veranderen

### 规则
- RDW 决定是否批准（不是自动的）
- 地址必须在荷兰
- 公司（rechtspersoon）必须未破产且有活跃 KVK 注册
- **公司通讯地址永不过期**（只要 KVK 有效）
- 该地址仅用于 RDW 邮件，不与其他机构共享

### 申请流程
1. 写一封**签字信**，包含：
   - 请求设置/更改/取消通讯地址
   - 荷兰通讯地址
   - **详细解释为什么不能把信寄到注册地址**（理由示例：B.V. 地址是共享办公/注册
     地址，无人签收车辆信件，车辆实际由个人使用及保管）
   - KVK 号码 + vestigingsnummer（门店号）
   - 授权签字人的 BSN、全名、出生日期
   - 如无 BSN，附有效身份证明复印件
2. 登录 RDW 门户：https://www.rdw.nl/correspondentieadres
3. 填写信息 + 上传签字信和文件
4. RDW 5 个工作日内批复
5. 通过后，**该名下所有车辆**的 RDW 信件全部寄到通讯地址

### 费用
免费

## 解决方案二：PostNL 邮件转寄（备用）

### 操作
- 在 PostNL 设置 **Doorsturen**（邮件转寄）
- B.V. 地址 → 个人住址
- 费用：€30–50/年
- **副作用**：所有信件都转（不只是车的），包括税务局、银行信件

## 解决方案三：DigiD Machtigen（数字化）

### 操作
1. B.V. 在 RDW 注册 **Machtigen（授权）**，授权个人 DigiD 查看车辆信息
2. 在 MijnRDW 设置 **digitale post**（电子信件）
3. 所有 RDW 信件只在 DigiD 里显示电子版
4. 物理上不需要收纸质信

### 路径
https://mijn.rdw.nl

## 解决方案四：B.V. 卖车给个人（最彻底）

### 操作
- B.V. 以市场价把车卖给个人
- 车从 B.V. 名下转到个人名下
- 所有人是个人 → 所有信件自然寄到个人住址
- B.V. 收回车款 → 同时解决「holding 钱出不来」的问题

### 税务影响
- 个人成为车主 → 需缴纳 box 3 财富税（车辆价值计入资产）
- B.V. 卖车 → 如卖价高于账面价值，B.V. 需缴公司税（Vpb）

## 解决方案五：租赁模式（预防性）

如果还没买车：
- B.V. 不买断，做 financial lease / operational lease
- 车登记在租赁公司名下
- 个人是**指定驾驶员**
- 信件 → 租赁公司 → 电子化转发给个人
- B.V. 月付租金（可抵税），车不在 B.V. 资产负债表

## 推荐组合

> **RDW 通讯地址（方案一）+ PostNL 邮件转寄（方案二）双重保险**

- RDW 通讯地址：解决 90% 车辆相关信件
- PostNL 转寄：兜底（停车罚单等市政信件可能走不同系统）

## 注意事项

### ⚠️ 罚款信（boete）
- RDW 罚款信默认寄到车主注册地址
- 设置通讯地址后 RDW 会转
- 但**市政停车罚单**可能走不同系统，如果寄到 B.V. 地址收不到 → 滞纳金叠加
- 建议同时开 PostNL 转寄

### ⚠️ 税务局信件
- RDW 通讯地址**只影响 RDW 发的信**
- Belastingdienst（税务局）的信仍然寄到 B.V. 注册地址
- 如需转税务局信件，需单独在 Belastingdienst 改地址

### ⚠️ 保险信
- 保险公司信件通常按投保时填写的地址发送
- 与 RDW 通讯地址无关
